# sor-frontend (SOR Monitoring Dashboard)

'sor-api' 백엔드 시스템의 실시간 주문 처리 흐름과 상태 변화를 직관적으로 검증하기 위해 구축한 모니터링 대시보드 레포지토리입니다.

AI 프로토타이핑 도구(v0)를 활용하여 대시보드 UI를 신속하게 생성하고, 백엔드 REST API와의 실시간 데이터 동기화 및 인터페이스 정합성 검증에 집중했습니다.

---

## Tech Stack & Tools
* **AI Prototyping**: v0 (GenAI 기반 UI 프로토타이핑)
* **Frontend Basics**: HTML / CSS / JavaScript

---

## Key Focus & Features
- **v0(GenAI) 기반 UI 프로토타이핑**: 프론트엔드 개발 소요 시간을 최소화하고 백엔드 API 설계 및 검증에 집중
- **백엔드 REST API 연동**: 엔드포인트 연동을 통한 주문 목록 조회
- **상태별 모니터링 뷰**: 주문 상태(접수, 검증 완료, 라우팅 완료, 체결 완료, 거절) 통계 요약 카드 및 필터링 기능 연동

---

## Key Experience
- GenAI 도구(v0)를 활용해 풀스택 모니터링 환경을 신속하게 구현하는 웹 프로토타이핑 경험
